# Warmup Exercises (start here)

These are much smaller than `exercises/EXERCISES.md` — one concept per file,
with blanks to fill in and the expected output shown so you know
immediately if you got it right. Do these first, in order.

## How to do each one

1. Open the file in a text editor.
2. Read the comment at the top — it tells you the expected output.
3. Replace every `___` with the right thing.
4. Save, then run it:
   ```bash
   chmod +x scripts/00-warmup/1-variables.sh
   ./scripts/00-warmup/1-variables.sh
   ```
5. Compare your output to the "Expected output" in the comment.
   - Matches? Move to the next file.
   - Doesn't match? Read the error message carefully — it usually tells you
     exactly what's wrong (e.g. `command not found` often means a typo).

## Order

| File | What it teaches | Difficulty |
|---|---|---|
| `1-variables.sh` | setting and using variables | ⭐ |
| `2-if-statement.sh` | basic if/else, run with an argument | ⭐ |
| `3-loop.sh` | a simple `for` loop | ⭐ |
| `4-function.sh` | defining and calling a function | ⭐⭐ |
| `5-combine.sh` | write a full tiny script yourself | ⭐⭐ |

Stuck on any blank for more than a couple minutes? Just paste me the file
and what error you're getting — that's normal, not a sign you're behind.

## After this

Once all 5 run correctly, go to `exercises/EXERCISES.md` — it'll feel much
easier after this warmup, since it's the same building blocks, just
combined into bigger scripts.
